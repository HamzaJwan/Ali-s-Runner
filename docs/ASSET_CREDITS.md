## Rules

* CC0 preferred. CC-BY only if attribution is documented in the table above and credited somewhere visible (final location to be decided when a credits screen exists).
* Never add a row for an asset whose license is unknown or undocumented — if you can't fill in every column, don't use that asset.
* AI-generated custom assets (Fatima, Zainab, Jomana, Father, Libyan buildings, Zliten-specific objects) are not "sourced" in the sense this file tracks — see `docs/ASSET_SOURCING_PLAN.md` Section 6 for why those stay custom rather than free-sourced.
* Remove the example row once the first real asset is added.
