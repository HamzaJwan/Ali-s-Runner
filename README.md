# Ali Runner

A 2D side-scrolling runner built in Godot 4.7, set in Al-Mantarah, Zliten, Libya. A personal, family-friendly project — warm, simple, and emotionally driven by a story about Ali and his family.

## Current Status

* v0.5 — Playable visual prototype: complete.
* v0.55 — Story and future feature documentation: complete.
* v0.6 — Gameplay feel polish: complete.
* v0.61 — Obstacle spawn offscreen fix: complete (obstacles now spawn at `x = 1292`, outside the visible play area, and enter naturally).

See `docs/AI_GAME_ROADMAP.md` for the full milestone roadmap and what's next.

## How to Open in Godot

1. Open Godot 4.7.
2. Choose "Import" and select this project's `project.godot` file.
3. Press F5 or F6 to run.

Main scene: `res://scenes/Main.tscn`
