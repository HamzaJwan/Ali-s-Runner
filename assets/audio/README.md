# Audio

Audio is planned later only. Do not add files without license documentation.

No audio files exist yet anywhere under this folder. See `docs/AUDIO_DESIGN_PLAN.md` for the full sound list, file format rules (WAV for short SFX, OGG for music/ambience), bus layout, and licensing rules (CC0 preferred, CC-BY only with documented attribution).

When an audio file is actually added, create or update `docs/AUDIO_CREDITS.md` with: file name, source URL, author, license, usage in game, and whether attribution is required.

Subfolders:

* `ui/` — button click, dialogue blip.
* `player/` — jump, land.
* `gameplay/` — obstacle hit.
* `story/` — checkpoint, reward, game over, victory sounds.
* `ambience/` — wind, birds, city loops.
* `music/` — main loop, checkpoint, victory themes.

Do not download or place any audio file here without documenting its license first.
